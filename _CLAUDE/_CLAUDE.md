# _CLAUDE: área de trabalho da IA

O Claude tem autonomia total aqui.

| Pasta | Conteúdo |
|---|---|
| `logs/` | Um arquivo por dia de trabalho (`AAAA-MM-DD.md`): o que foi feito, o que mudou no cofre |
| `specs/` | Planos de implantação, especificações, propostas de modelos novos |
| `skills/` | Índice das skills SPARTA e de quando usar cada uma |
| `rascunhos/` | Rascunhos que ainda não foram validados pelo Celso |

**Podagem mensal:** apagar logs com mais de 90 dias (o resumo fica no fechamento mensal), rascunhos superados e arquivos temporários.
**Validação:** nada sai daqui para uma gaveta como conhecimento permanente sem o Celso revisar.
